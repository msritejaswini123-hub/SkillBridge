# Slim dependency list for deploying on a small free instance (Render, Railway...)
#
# WHY THIS FILE EXISTS
# The full requirements.txt also installs scikit-learn + numpy + scipy (~120 MB).
# On a 512 MB free instance that build is slow and the extra memory at runtime is
# tight. SkillBridge's ML layer is optional by design: without scikit-learn the
# recommendation engine falls back to the transparent rule-based score, the "ML
# shortlist likelihood" chip disappears, and the /ml-info page says the layer is
# off. Every other feature works identically.
#
# Use this file:      pip install -r requirements-render.txt
# Want ML in prod?    use requirements.txt instead and pick a paid instance.
