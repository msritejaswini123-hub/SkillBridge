==========================================================
 SkillBridge - HOW TO RUN (beginner friendly)
==========================================================

You need Python 3.9 or newer. Nothing else. No Node, no React,
no MongoDB. Just copy-paste the lines below, one at a time.


----------------------------------------------------------
 STEP 0 - OPEN THE PROJECT
----------------------------------------------------------
Open this folder in VS Code, then open a terminal inside it:
   View  ->  Terminal      (or press  Ctrl + `  )

Make sure the terminal says you are inside the "sandwich" folder.


----------------------------------------------------------
 STEP 1 - MAKE A VIRTUAL ENVIRONMENT  (do this once)
----------------------------------------------------------
A "venv" is a private box for this project's libraries.

Mac / Linux:
   python3 -m venv venv

Windows:
   python -m venv venv

(If a "venv" folder already exists, skip this step.)


----------------------------------------------------------
 STEP 2 - TURN THE VENV ON  (do this every time)
----------------------------------------------------------
Mac / Linux:
   source venv/bin/activate

Windows:
   venv\Scripts\activate

You will now see (venv) at the start of your terminal line.
That is how you know it worked.


----------------------------------------------------------
 STEP 3 - INSTALL THE LIBRARIES  (do this once)
----------------------------------------------------------
   pip install -r requirements.txt


----------------------------------------------------------
 STEP 4 - BUILD THE DATABASE  (do this once)
----------------------------------------------------------
   python init_db.py

This creates database/portal.db and fills it with demo data:
23 internships, 6 companies, 7 students, courses.


----------------------------------------------------------
 STEP 5 - START THE WEBSITE
----------------------------------------------------------
   python app.py

Then open this address in your browser:

   http://127.0.0.1:5000

To stop the server, click the terminal and press  Ctrl + C

==========================================================
 IF SOMETHING GOES WRONG
==========================================================
"command not found: python"
   -> type  python3  instead of  python

"No module named flask"
   -> the venv is off. Go back to STEP 2, then STEP 3.

"Port 5000 is already in use"  (common on Mac)
   -> run:  python app.py --port 5001
   -> then open  http://127.0.0.1:5001

"I want a clean database again"
   -> run:  python init_db.py --reset

The website is slow on the very first page load
   -> normal. The small ML model trains once at startup
      (about 1 second), then it is cached.
